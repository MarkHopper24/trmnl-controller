# Security reports

Please use this repository's GitHub **Security → Report a vulnerability** flow for private reports when available. Do not post tokens, credential files, private account exports or personal automation data in an issue. Revoke any exposed credential with its provider.

See [the security and privacy model](docs/security.md) for credential storage, local data, network controls and limitations. The project is a local single-user integration and has not received an independent security audit.
